Tentang Sistem

Sistem ini merupakan implementasi model klasifikasi tumor otak berbasis citra MRI ke dalam aplikasi web menggunakan Flask.

Backend sistem dibangun menggunakan Flask berbasis RESTful API. Sistem menerima input berupa citra MRI, melakukan preprocessing, kemudian memproses citra menggunakan model deep learning untuk menghasilkan prediksi kelas tumor otak.

Teknologi yang Digunakan
  • Python
  • Flask
  • TensorFlow / Keras
  • HTML, CSS, Bootstrap
  • JavaScript
Sistem ini dibuat sebagai bagian dari tugas akhir dan digunakan untuk kebutuhan penelitian.
