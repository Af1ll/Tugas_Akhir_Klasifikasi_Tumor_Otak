Sistem Klasifikasi Tumor Otak Berbasis Citra MRI

Sistem ini digunakan untuk mengklasifikasikan citra MRI otak ke dalam beberapa kelas, yaitu glioma, meningioma, pituitary, dan no_tumor menggunakan model deep learning.

Mulai Prediksi
Alur Sistem
1. Upload citra MRI otak
2. Sistem melakukan preprocessing
3. Model melakukan klasifikasi
4. Hasil prediksi ditampilkan
RESTful API

Backend dibangun menggunakan Flask dengan endpoint API untuk menerima input citra dan menghasilkan prediksi.

Deep Learning

Model klasifikasi digunakan untuk mengenali pola pada citra MRI otak.

Hasil Prediksi

Sistem menampilkan kelas hasil prediksi beserta nilai confidence dari model.
